# 在鸿蒙电脑上运行 Omarchy（通过 OSEasy）

给普通用户的安装说明：只用鸿蒙的**文件管理器**和 **OSEasy** 的界面，全程**不需要 root、不需要 hdc、不需要命令行**。

> 状态：草稿。系统已改为"状态保存"的持久化方案（根文件系统放在共享文件夹的一个磁盘镜像里，
> 不随"再次安装"丢失）。下面的"日常使用 / 你的文件存哪 / 常见问题"几节还停留在旧的"每次重装"
> 写法，会在"无 root 全程走查"验证通过后，连同截图一起按持久化方案改定。个别按钮文案/位置以
> 你机器上的 OSEasy 版本为准。

## 这是什么

这是把 [Omarchy](https://omarchy.org)（基于 Arch Linux 的 Hyprland 桌面）跑在鸿蒙电脑的
OSEasy 虚拟机里的一套系统。

它是一台**能保存状态的 Linux 电脑**：你装的软件、改的设置、存的文件都会一直保留。系统盘是
一个存在共享文件夹里的磁盘镜像，不随 OSEasy 的"再次安装"丢失。

- 首次使用要联网安装 Omarchy，大约 15–30 分钟，一次性（见"安装"）。
- 之后每次开机十几秒进桌面，上次的状态都在。
- OSEasy 对 Linux 客户机只提供"再次安装"按钮——在本系统里**它就是"开机"**，不会清空你的数据。

## 准备

1. **设备**：一台鸿蒙 PC（HarmonyOS，arm64）。窗口内刷新率实测 **120Hz**（Hyprland 与
   fastfetch 都报 120Hz）。Omarchy 跑在 OSEasy 给的是一个**固定大小的浮动窗口**：没有最大化
   按钮、也不能拖边框放大，无法全屏（见 FAQ）。
2. **装 OSEasy**：在应用市场搜"OSEasy 虚拟机"安装。首次使用它提供试用（一台设备通常只能
   试用一次，注意有效期，见 FAQ）。
3. **下载我们的文件**（用浏览器或文件管理器下载，放到"下载 / Download"目录）：
   - `oseasy-probe.iso`（安装盘）
   - 校验：对照 Release 里的 `SHA256SUMS`（可选，手机/电脑上校验都行）。
   - 如果你下载的是"小 ISO + 单独的磁盘镜像"版本，请把磁盘镜像
     `omarchy-pure.img.zst` 放进"文件管理器 → **Documents**"目录（虚拟机会从这里读它）。
     如果你下载的是"大 ISO（已内置镜像）"版本，就只需要那一个 ISO。

## 安装（全程点界面）

1. 打开 **OSEasy 虚拟机**。
2. 点 **立即创建**（第一次）。
3. 选择安装镜像：点"点击选择 ISO"，在文件选择器里选 `oseasy-probe.iso`，打开。
4. 如果弹出"镜像不符合要求 / 安装过程异常"之类的提示，这是因为我们不是 Windows——
   选 **继续安装 / 仍要安装**，一路 **下一步 / 开始安装**。
5. 之后**全自动**：它会写入系统、装显卡驱动、然后自动重启进入 Omarchy 桌面，整个过程
   约 80 秒，不需要你操作。期间 OSEasy 窗口外层可能一直显示"正在安装 Windows 11…"，
   **这是正常的**（见 FAQ）——以虚拟机画面里是否出现桌面为准。

## 日常使用：开机 / 关机

- **关机**：在 Omarchy 桌面里正常关机（开始菜单 / 电源，或终端 `systemctl poweroff`）。
- **再次开机**：虚拟机关了以后，OSEasy 只会给你一个 **再次安装** 按钮——**这个就是"开机"**。
  点它，约 80 秒自动回到桌面。

  为什么是"再次安装"而不是"开机"：OSEasy 收不到 Linux 的"装好了"信号，所以每次都当成
  重新安装。系统盘会还原，但**你放在 Documents 里的文件不会丢**。

## 你的文件存哪（重要）

把要保留的文件放在桌面里的 **`~/Documents`**（它链接到共享文件夹 `~/Shared`）。这些文件
实际存在鸿蒙宿主上，在**文件管理器 → Documents** 里也能直接看到和管理。因为它们不在系统
盘上，所以每次"再次安装"都不会丢。

- 虚拟机里：`~/Documents`（= `~/Shared`）
- 鸿蒙宿主里：文件管理器 → Documents
- 不要把要长期保留的东西放在桌面系统盘的其它位置（比如 `~/Downloads`、`~/.config`），
  那些会在下次开机时还原。

## 常见问题

**OSEasy 一直显示"正在安装 Windows 11…预计 13 分钟"，是卡住了吗？**
没卡。OSEasy 是给 Windows 用的，它靠 Windows 客户机的一个信号判断"装完了"；我们是 Linux，
不发这个信号，所以它外层会一直显示"正在安装"。**看虚拟机画面本身**——里面已经是 Omarchy
桌面就说明好了。

**关机后只剩"再次安装"，没有"开机"？**
"再次安装"就是开机，点它约 80 秒进桌面。这是 OSEasy 对 Linux 客户机的限制，不是故障。
你的文件在 Documents 里不会丢。

**提示"检测到有其它虚拟机正在运行，请先将其关闭后再试"？**
鸿蒙一次只能跑一个虚拟机。先把别的虚拟机（包括别的 App 起的）关掉；如果你确认没有别的在
跑，等几秒再点一次通常就好。

**屏幕刷新率？** 窗口内实测 120Hz（Hyprland / fastfetch 报告的值）。

**能全屏吗？** 不能。OSEasy 给 Linux 虚拟机的是一个固定大小的浮动窗口——标题栏只有"最小化 /
关闭"，没有最大化按钮，也不能拖边框缩放。这是 OSEasy 当前的限制（设备本身是 2in1、支持全屏，
是 OSEasy 没给虚拟机窗口开），不是本镜像的问题；我们已把"开放全屏/最大化"列进了给 OSEasy 的
需求清单。窗口内的画面是清晰的（1:1 渲染），只是不能放大铺满屏。

**要输密码吗？** 默认开机自动登录进桌面，不用输密码（可自行在系统里改）。

**试用到期了怎么办？** OSEasy 的试用是它自己的（和本镜像无关）。有效期以 OSEasy 界面里显示
的为准；到期后按 OSEasy 的提示处理。

## 卸载

在 OSEasy 里对这台虚拟机选 **取消 / 删除** 即可。你在 Documents 里的文件不会被删（它们在
鸿蒙宿主上，需要的话到文件管理器里自行清理）。
