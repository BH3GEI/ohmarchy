# 在鸿蒙电脑上运行 Omarchy（通过 OSEasy）

给普通用户的安装说明：只用鸿蒙的**文件管理器**和 **OSEasy** 的界面，全程**不需要 root、不需要 hdc、不需要命令行**。

> 状态：草稿，待"无 root 全程走查"的截图补齐。个别按钮文案 / 位置、耗时以你机器上的
> OSEasy 版本和实测为准。

## 这是什么

这是把 [Omarchy](https://omarchy.org)（基于 Arch Linux 的 Hyprland 桌面）装进鸿蒙电脑的
OSEasy 虚拟机里的一套系统。镜像会写进虚拟机自己的磁盘，不走共享文件夹。

**数据怎么留、怎么丢（重要，先看这条）：**
- 在 Omarchy 桌面里**重启**（`systemctl reboot` 或开始菜单里的重启）：你装的软件、改的
  设置、存的文件都**保留**，下次开机直接进已装好的系统。
- 但虚拟机**关机**以后，OSEasy 对 Linux 客户机只给一个 **"再次安装"** 按钮，点它会**先清空
  磁盘再重装**——这会**丢掉上次的所有数据和改动**。
- 所以：**想留数据就在桌面里重启，别关机后再点"再次安装"。** 当试用 / 演示用则无所谓，每次
  "再次安装"都是一套干净的系统。

## 准备

1. **设备**：一台鸿蒙 PC（HarmonyOS，arm64）。窗口内刷新率实测 **120Hz**（Hyprland 与
   fastfetch 都报 120Hz）。Omarchy 在 OSEasy 里是一个**固定大小的浮动窗口**：没有最大化
   按钮、也不能拖边框放大，无法全屏（见 FAQ）。
2. **装 OSEasy**：在应用市场搜"OSEasy 虚拟机"安装。首次使用它提供试用（一台设备通常只能
   试用一次，注意有效期，见 FAQ）。
3. **下载我们的文件**（用浏览器或文件管理器下载，放到"下载 / Download"目录）：
   - `oseasy-probe.iso`（安装盘，已内置系统镜像，一个文件即可）。
   - 校验：对照 Release 里给出的字节大小（可选）。

## 安装（全程点界面）

1. 打开 **OSEasy 虚拟机**，点 **立即创建**（第一次）。
2. 如果弹"检测到 ISO 是否导入"，选 **取消**（别让它自动导入别的镜像）。
3. 点 **"点击选择 ISO"**，在文件选择器里选 `oseasy-probe.iso`，**打开**。
4. 点 **下一步**。如果弹"镜像不符合要求 / 安装过程异常 / 可能超出产品能力"之类的提示，这是
   因为我们不是 Windows——选 **继续安装 → 仍要安装**。
5. 到虚拟机配置页，点 **开始安装**。之后**全自动**：写入系统、首次开机扩满磁盘、自动重启进入
   Omarchy，整个过程约几分钟，不需要你操作。期间 OSEasy 窗口外层可能一直显示"正在安装
   Windows 11…"，**这是正常的**（见 FAQ）——以虚拟机画面里是否出现桌面为准。

## 首次开机：设置密码

第一次进系统会自动登录，然后弹出一个**全屏终端**，提示 **"请设置密码 / Set your password"**。
按提示输入一个**至少 8 位**的密码（要输两次，输入时不显示字符），成功后按回车关闭。

- 这个密码就是以后 `sudo`（管理员操作）用的密码。
- 设完以后照常**自动登录**进桌面，日常用不需要再输密码。

## 日常使用：重启 / 关机

- **重启（推荐，保留数据）**：在 Omarchy 桌面里重启（开始菜单 / `systemctl reboot`）。下次
  开机 GRUB 会直接进你已装好的系统，软件、设置、文件都在。
- **关机**：在桌面里正常关机（`systemctl poweroff`）。关机后 OSEasy 只会给 **"再次安装"**
  按钮，点它会**清盘重装**（约几分钟进桌面），**上次的数据会丢**。所以除非你不在乎数据，否则
  别用"关机 + 再次安装"当"重启"。

## 常见问题

**OSEasy 一直显示"正在安装 Windows 11…预计 13 分钟"，是卡住了吗？**
没卡。OSEasy 是给 Windows 用的，它靠 Windows 客户机的一个信号判断"装完了"；我们是 Linux，
不发这个信号，所以它外层会一直显示"正在安装"。**看虚拟机画面本身**——里面出现 Omarchy
桌面就说明好了。

**关机后只剩"再次安装"，没有"开机"？**
这是 OSEasy 对 Linux 客户机的限制（它收不到 Linux 的"装好了"信号），不是故障。"再次安装"
会**清盘重装**，不保留上次数据。想保留数据，请在桌面里**重启**而不是关机。

**提示"检测到有其它虚拟机正在运行，请先将其关闭后再试"？**
鸿蒙一次只能跑一个虚拟机。先把别的虚拟机（包括别的 App 起的）关掉；如果你确认没有别的在
跑，等几秒再点一次通常就好。

**屏幕刷新率？** 窗口内实测 120Hz（Hyprland / fastfetch 报告的值）。

**能全屏吗？** 不能。OSEasy 给 Linux 虚拟机的是一个固定大小的浮动窗口——标题栏只有"最小化 /
关闭"，没有最大化按钮，也不能拖边框缩放。这是 OSEasy 当前的限制（设备本身是 2in1、支持全屏，
是 OSEasy 没给虚拟机窗口开），不是本镜像的问题；我们已把"开放全屏 / 最大化"列进了给 OSEasy
的需求清单。窗口内的画面是清晰的（1:1 渲染），只是不能放大铺满屏。

**屏幕过一会变黑了？** 空闲一段时间会进屏保、再久会关屏（Omarchy 默认行为）。动一下鼠标或
按任意键就回来。首次设密码之前不会黑屏。

**OSEasy 弹"安装过程出现异常，可能是 ISO 镜像的 install.wim 损坏或安装过程被人为取消"？**
这是 OSEasy 按 Windows 的方式误报（我们不是 Windows，没有 install.wim），**虚拟机其实是好的**。
直接点 **"确定"** 关掉这个提示即可。
⚠️ **千万别在 OSEasy 的对话框里点"取消"**——在"安装失败"那类对话框里，**"取消"会删掉这台
虚拟机**，下次就得从 ISO 重装（约几分钟）。要继续用就只点"确定"或"再次安装"，或者直接关掉
OSEasy 窗口。

**试用到期了怎么办？** OSEasy 的试用是它自己的（和本镜像无关）。有效期以 OSEasy 界面里显示
的为准；到期后按 OSEasy 的提示处理。

## 卸载

在 OSEasy 里对这台虚拟机选 **取消 / 删除** 即可。
